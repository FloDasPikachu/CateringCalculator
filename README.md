# CateringCalc - Mixology & Event Calculation Tool

Ein plattformübergreifendes B2B-Kalkulationswerkzeug für Event-Caterer, Bartender und Veranstalter zur exakten Berechnung von Getränkemengen, Einkaufslisten, Eisbedarf und Margen.

## 🛠 Tech Stack
* **Framework:** .NET 8 / .NET MAUI Blazor Hybrid
* **Sprache:** C# / Razor
* **Datenbank:** SQLite via Entity Framework Core
* **Architecture:** Clean Architecture / Layered Architecture
* **Testing:** xUnit
